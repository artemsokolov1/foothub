# Foothub Randomizer 🎲

Мобильное приложение на React Native для случайного выбора занятия из предопределенного списка.

## Описание

Приложение позволяет пользователю нажать кнопку "Выбрать" и получить случайное занятие из списка. Результат отображается с красивой анимацией (fade-in, масштабирование и вращение).

## Особенности

- ✨ Красивая анимация при выборе элемента
- 🎨 Современный UI дизайн
- 📱 Поддержка iOS и Android
- 🔄 Возможность повторного выбора
- 🎯 Легко настраиваемый список элементов

## Установка и запуск

### Предварительные требования

- Node.js (версия 14 или выше)
- npm или yarn
- Expo CLI (устанавливается автоматически)

### Установка зависимостей

```bash
npm install
```

или

```bash
yarn install
```

### Запуск приложения

**Для запуска в режиме разработки:**

```bash
npm start
```

или

```bash
yarn start
```

Это откроет Expo Developer Tools в браузере, где вы сможете:
- Запустить приложение на физическом устройстве через приложение Expo Go
- Запустить в эмуляторе Android (необходим Android Studio)
- Запустить в симуляторе iOS (необходим Xcode, только на macOS)
- Запустить в веб-браузере

**Запуск на конкретной платформе:**

```bash
# Android
npm run android

# iOS (только на macOS)
npm run ios

# Web
npm run web
```

## Настройка списка элементов

Чтобы изменить список элементов для случайного выбора, отредактируйте файл `src/data/items.js`:

```javascript
export const items = [
  "Посмотреть фильм 🎬",
  "Поиграть в настолки 🎲",
  "Прогулка на свежем воздухе 🚶",
  // Добавьте свои элементы здесь
];
```

## Технологии

- **React Native** - фреймворк для создания нативных приложений
- **Expo** - инструменты для упрощения разработки
- **Animated API** - встроенная система анимации React Native

## Как это работает

1. Пользователь нажимает кнопку "Выбрать"
2. Приложение использует `Math.random()` для выбора случайного индекса
3. Выбранный элемент отображается с анимацией:
   - Fade-in (плавное появление)
   - Scale (масштабирование)
   - Rotate (вращение 360°)
4. Пользователь может нажать кнопку снова для нового выбора
