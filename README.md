# Randomizer App

Мобильное приложение на React Native + Expo для случайного выбора занятия на вечер.

## Функционал

- 🎲 Случайный выбор элемента из списка
- ✨ Красивая анимация при выборе
- 🔄 Возможность повторного выбора
- 📱 Современный UI

## Установка

```bash
npm install
```

## Запуск

```bash
npx expo start
```

После запуска вы увидите QR-код. Отсканируйте его с помощью:
- **iOS**: Приложение Camera
- **Android**: Приложение Expo Go

Или нажмите:
- `a` — для запуска на Android эмуляторе
- `i` — для запуска на iOS симуляторе
- `w` — для запуска в браузере

## Структура проекта

```
App.js                  — точка входа
app.json                — конфигурация Expo
package.json            — зависимости
src/
  components/
    RandomPicker.js     — основной компонент рандомизатора
  data/
    items.js            — список элементов для случайного выбора
  styles/
    theme.js            — цвета и стили
```

## Технологии

- React Native
- Expo SDK 50
- React 18.2
